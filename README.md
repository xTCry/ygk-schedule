# ЯГК Schedule parser

Парсер учебного расписания _Ярославского градостроительного колледжа_ с дальнейшей публикацией нормализованных JSON и iCalendar данных.

## Требования

- Node.js 22+

## Команды

```bash
npm install
npm run check
npm run build
```
